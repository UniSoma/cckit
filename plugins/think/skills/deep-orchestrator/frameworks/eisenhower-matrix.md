<objective>
Apply the Eisenhower matrix to $ARGUMENTS (or the current discussion if no arguments provided).

Categorize items by urgent/important quadrants to clarify what to do now, schedule, delegate, or eliminate.
</objective>

<process>
1. List all items to be prioritized
2. For each item, evaluate: Is it important? Is it urgent?
3. Place each item in the appropriate quadrant
4. Assign specific actions per category
</process>

<output_format>
**Q1: Do First (Important + Urgent)**
- [Item]: [specific action]

**Q2: Schedule (Important + Not Urgent)**
- [Item]: [when to do it]

**Q3: Delegate (Not Important + Urgent)**
- [Item]: [who or how to handle quickly]

**Q4: Eliminate (Not Important + Not Urgent)**
- [Item]: [why it can be dropped]

**Immediate Focus:**
[Single sentence on what to do right now]
</output_format>

<success_criteria>
- Every item is clearly categorized
- Important vs urgent distinction is accurate
- Q1 items have immediate actions
- Q2 items have scheduled times
- Q3 items have delegation paths
- Q4 items are eliminated without guilt
- Reduces overwhelm through clear prioritization
</success_criteria>
