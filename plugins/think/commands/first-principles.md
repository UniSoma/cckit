<objective>
Apply first principles thinking to $ARGUMENTS (or the current discussion if no arguments provided).

Break down beliefs into fundamental truths and rebuild understanding without assumptions or conventions.
</objective>

<process>
1. State the problem or belief being examined
2. List all current assumptions
3. Challenge each assumption: Is this actually true, or just conventional wisdom?
4. Identify the irreducible base truths
5. Reconstruct a solution or understanding from fundamentals only
</process>

**Current Assumptions:**
- [Assumption 1]: [verified/unverified/false]
- [Assumption 2]: [verified/unverified/false]
- [Assumption 3]: [verified/unverified/false]

**Fundamental Truths:**
- [Truth 1]: [why this is irreducible]
- [Truth 2]: [why this is irreducible]

**Rebuilt Understanding:**
Starting only from the fundamental truths, [new perspective or solution]

**New Possibilities:**
[What becomes possible when we drop false assumptions]
</output_format>

<success_criteria>
- Surfaces hidden assumptions
- Distinguishes convention from necessity
- Identifies truly irreducible base truths
- Opens new solution pathways
- Avoids reasoning by analogy
- Moves beyond inherited thinking patterns
</success_criteria>
