---
description: Analyze what you give up by choosing this option
argument-hint: [choice or leave blank for current context]
---

<objective>
Apply opportunity cost analysis to $ARGUMENTS (or the current discussion if no arguments provided).

Every choice has a hidden cost: what you give up by not choosing the best alternative.
</objective>

<process>
1. Identify the choice being considered
2. List all resources required (time, money, energy, attention)
3. For each resource, identify the best alternative use
4. Calculate the true cost: chosen option + foregone value of best alternative
5. Determine if the choice is still worth it
</process>

<output_format>
**Choice:** [what you're considering doing]

**Resources Required:**
- Time: [hours/days/weeks]
- Money: [amount]
- Energy/Attention: [cognitive load]
- Other: [relationships, reputation, etc.]

**Best Alternative Uses:**
- With that time, could instead: [alternative + value]
- With that money, could instead: [alternative + value]
- With that energy, could instead: [alternative + value]

**True Cost:**
Choosing this means NOT doing [best alternative], which would have provided [value].

**Verdict:**
[Is the chosen option worth more than the best alternative?]
</output_format>

<success_criteria>
- Makes hidden costs explicit
- Compares against best alternative, not just any alternative
- Considers all resource dimensions (not just money)
- Reveals when "affordable" options are actually expensive
- Enables more informed trade-off decisions
</success_criteria>
